# data/sample

Fictional member docs used by tests, CI, and demos. Mirrors the shape of the real data in the private `bg-center-data` repo (member count, doc length, PT/EN mix, section structure) but contains no real personal information — see ADR-0003 and ADR-0005.

Each member is one Markdown file with YAML frontmatter, per ADR-0004. Not yet populated — adding fictional members with "planted traps" (lookalike names, shared facts, clear extremes, cross-member stories, deliberately missing facts) is part of the MVP build plan in the root `CLAUDE.md`.
